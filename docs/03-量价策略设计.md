# 量价策略设计 · 用户观点驱动的修订版

> 2026-09-24 · 基于用户核心观点修订,检验规范沿用《02-行动计划》第 2 节(RankIC/分层/样本内外/成本/涨跌停约束)
> 核心转变:**基本面因子从 alpha 序列除名,降级为排雷过滤器;alpha 全部从量价+事件里找。只做多。**

---

## 0. 对用户观点的量化翻译

用户原话 → 量化对应物:

| 用户直觉 | 机制(学术/市场结构) | 因子化 |
|---|---|---|
| PE/ROE 对股价难有强边际贡献 | A股散户定价权高、换手快,慢变量跑不过交易行为 | 基本面→只做**安检过滤** |
| 公司不存在严重问题(哪怕亏损) | 排雷:避免退市/爆仓/踩雷的尾部损失 | 过滤器 G0 |
| 市场关注度 | 注意力驱动交易(attention-driven) | G1/G2 |
| 交易量变动,放量≠涨 | **分歧+卖空受限**:高换手=意见分歧被套牢(Miller 1977, Hong-Stein 2007)→ 高位放量常是派发;低位缩量后放量=卖压衰竭/吸筹 | G4/G5,分位置讨论 |
| 日内波动率变化 | 蓄势(压缩)→启动(扩张);ONeil VCP 结构 | G7/G8 |
| 股票动量 | A股短期反转强、中期动量弱→用「动量启动+质量」不用裸动量 | G9/G10/G11 |
| VWAP | 接口有日线均价字段(=当日 VWAP);vwap 序列≈持仓成本分布的粗近似 → close 相对 vwap 带的位置=获利盘/支撑位代理(筹码区) | G6 |
| 斐波那契回撤 | 本质=回撤深度在近期高低区间的位置;38.2/50/61.8 的魔法数字无稳定实证,**连续化处理,让数据自己选区间** | G12 |

**一句话**:要找的是「蓄势→启动」结构 = 关注度异常 + 量能异常 + 波动先收缩后扩张 + 价格站上量加权成本区 + 动量确认。这就是 Wyckoff 吸筹→拉升 的可计算版本,也和民间「放量见底→反转→启动」说法同构。

---

## 1. 排雷过滤器 G0(基本面唯一保留的岗位)

剔除:ST/*ST、上市不满1年、**质押比例>50%**(接口可取)、日均成交额后20%、负债率>85%。
> 原则:**基本面只做安检,不做选美**——亏损公司可以买,有退市/爆仓风险的不碰。这完全保留用户「不存在严重问题」的原意。

---

## 2. 量价因子库(12 个,全部日线可算,只做多)

| # | 因子 | 构造 | 捕捉什么 | 方向先验(让数据裁决) |
|---|---|---|---|---|
| G1 | 换手率水平 | 20日均换手率 | 情绪过热/分歧度 | 低好(反转逻辑) |
| G2 | 关注度跃升 | 5日均换手 / 60日均换手 | 注意力突增起点 | 高好(启动信号),与G1方向相反→**同维度两态** |
| G3 | 成交额分位变化 | 成交额市场分位的5日变化 | 相对量能迁移 | 高好 |
| G4 | 放量倍数 | 5日均量 / 60日均量 | 量能异常 | **分位置**:低位高好、高位低好(交互G12) |
| G5 | 量价相关性 | 20日 corr(close, volume) | 放量是有人接还是有人跑 | 正好(放量上涨健康) |
| G6 | VWAP 偏离(获利盘代理) | close / 20日vwap均价带 - 1 | 持仓者平均盈亏状态/筹码支撑 | 适度为好(过高=抛压,过低=套牢) |
| G7 | 日内振幅趋势 | 5日均振幅 / 60日均振幅 | 波动收缩→扩张拐点 | 收缩后启动:交互项 |
| G8 | 波动不对称 | 上行半波动 / 下行半波动 | 上涨/下跌日的力道结构 | 高好 |
| G9 | 短期反转 | 20日收益率 | A股最强 | 低好 |
| G10 | 特质动量 | 剔除市场后的60日残差收益 | 不带β的纯alpha动量 | 高好(学术:A股显著) |
| G11 | 动量质量 | 60日内上涨日占比 | 涨势的「做工」 | 高好 |
| G12 | 回撤位置(斐波那契连续化) | (120日高-close)/(120日高-120日低) | 回撤深度;区间中部≈斐波那契带 | **交互项**:与G4/G9组合才有意义 |

> 设计原则:单一因子只测主效应一次(防数据挖掘);他说的「放量见底反转」这类**条件结构**全部放进策略层做交互项,不进单因子库——先验假设少而明确。

## 3. 候选策略(只做多,月/双周调仓)

- **P1 量价共振(主推)**:G0 过滤 → 全市场按「关注度+量价健康度+波动结构+动量确认」四组打分等权合成 → Top50。对应:协作伙伴「多视角叠加」经验的规范版。
- **P2 缩量回踩反转(用户偏好的直接操作化)**:前置条件=G10 动量为正(先有趋势)→ 回撤至区间 35–70%(斐波那契带,连续变量)→ 近5日量能萎缩(卖压衰竭)→ 次日介入,持有至动量破坏。这是「放量见底→反转→启动」的买点规则化,**事件型策略,交易次数少,重点看盈亏比不看胜率**。
- **P3 涨停记忆流(备用,时间富余才跑)**:G0 过滤 + 60日涨停次数 + 涨停后回踩不破(首板分歧转一致)。

## 4. 检验与防过拟合(不变,重申三关)

样本内 2015–2021 开发、2022–2026 只考试;walk-forward;每个策略交易次数 ≥ 100 并报盈亏比/最大回撤(不只胜率);参数(窗口/TopN/调仓日)敏感性扫描;对 S 值不显著的交互组合**不硬解释,直接淘汰**。
