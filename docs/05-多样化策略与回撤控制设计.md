# 第三波 · 多样化策略设计 + 独立回撤控制方案

> 2026-09-26 深夜 · 轻量回测筛选逻辑,好的细测
> 经验约束:①热度/趋势类信号在A股月频反向;②强IC≠能扛集中持仓(A1教训);③简洁性获胜;④只做多。

## 第一部分 · 策略设计(5 套,机制各不相同)

### S-A 「逆向温度计」(反转深化)
**一句话**:不选"跌得最多的",选"情绪退潮退得最干净的"。
- 因子 = 换手率分位(20日)的下降斜率 ×(-1) + 负收益幅度适中(跌幅 10%~30% 带内,排除阴跌无底的)
- 与 P1 的区别:P1 的 G1 是"水平低",S-A 是"温度在降";跌幅带约束避开价值陷阱
- 预期特征:熊市末期/震荡市强,单边牛市弱

### S-B 「冷门启航」(关注度从无到有)★重点
**一句话**:连续三个月没人理的股票,突然连续两周温和放量——主力进场的第一信号。
- 因子 = 过去 60 日换手率处于全市场后 30% && 近 10 日换手分位跃升至前 50% && 60日涨幅 < 15%(没起飞过)
- 事件型:满足条件的股票少,天然低持仓
- 预期特征:胜率不高但盈亏比大(启动段介入);与 P1(持续逆向)低相关

### S-C 「质量剔雷反转」(把排雷做成收益)
**一句话**:同样的超跌股,质押爆仓/财务恶化的不碰——P1 第一轮证明 alpha 在空头端,这里把"躲开空头端"显性化。
- 用量价代理排雷(不拉财务):20日内出现过 gap<-9% 开盘(暴雷跳空)的剔除;60日波动率前 20% 的剔除
- 因子 = G1+G6 原样,过滤后选 Top5
- 预期特征:回撤显著小于 P1,收益略让

### S-D 「双周动量守恒」(周期错位实验)
**一句话**:月频太慢吃不到启动段、周频成本太高——双周+换手成本动态预算。
- P1 四因子不动,双周调仓,但只换"分数变化超过阈值"的股票(守恒:持仓粘性)
- 预期特征:换手率降 30%+,成本降,看净收益是否反超月频

### S-E 「波动率分层轮动」(先选状态再选股)★重点
**一句话**:大盘波动高时持有低波股、波动低时持有高弹性股——先判断"什么天气",再选"穿什么衣服"。
- 状态 = 沪深300 20日波动率分位(>70% = 高波环境)
- 高波环境:选特质波动后 20%(防御);低波环境:选 P1 四因子 Top5(进攻)
- 预期特征:回撤明显小于纯 P1,牛市让渡部分收益

## 第二部分 · 独立回撤控制方案(4 个工具,单独交付)

> 设计为"可插拔模块",任何策略都能套;本轮单独回测,不融入上述策略。

| # | 工具 | 规则(通俗版) | 控制对象 |
|---|---|---|---|
| D1 | **组合波动熔断** | 组合 20 日波动率超过历史 80% 分位 → 仓位减半;回落到 50% 分位以下 → 恢复 | 系统性回撤 |
| D2 | **回撤阶梯减仓** | 组合从高点回撤 10% → 仓位降至 70%;15% → 50%;20% → 清仓休息,回到高点后恢复 | 自身回撤(自适应) |
| D3 | **持仓止损纪律** | 单票从买入价回撤 15% → 该票踢出,换入候选名单下一名(不动其他票) | 个股黑天鹅 |
| D4 | **趋势保险丝** | 基准指数(沪深300)跌破 60 日均线 → 整体仓位上限降至 50% | 熊市识别(最经典的择时) |

**评测口径**:每个工具分别套在 P1 上,与裸奔 P1 对比:年化/回撤/Calmar/收益牺牲量。**回撤控制天然牺牲收益,评价看"每降低1%回撤牺牲多少年化"性价比**。
